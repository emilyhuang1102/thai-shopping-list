# 泰國購物清單

手機版泰國旅行購物清單，包含商品參考圖片、分類篩選、購買勾選、自訂商品與清邁香氛品牌門市資訊。

## 功能

- 18 項預設商品與本機圖片。
- 點選「✓ 買到了」切換購買狀態。
- 自行新增商品名稱、分類、數量與備註。
- 商品與勾選紀錄保存在目前裝置的瀏覽器中。
- PAÑPURI 香包與 Smell Lemongrass 位於預設清單後面。

## 開啟

直接開啟 `index.html`，或使用靜態網站伺服器。
不需要安裝依賴或執行建置。

## GitHub Pages

儲存庫的 **Settings → Pages → Build and deployment**：
選擇 **Deploy from a branch**，分支選 **main**、資料夾選 **/(root)**，按 **Save**。

## 檔案

- `index.html`：預設商品與門市資訊。
- `app.js`：新增商品、勾選和篩選。
- `mobile.css`：手機版按鈕與補充版面樣式。
- `images/`：商品參考圖片。

資料保存在瀏覽器端，不會跨裝置自動同步。清除網站資料會清除自訂商品與勾選紀錄。
